Conferir um cupom

Copie para cá o que está na imagem do cupom. A página refaz a conta do código e confere se os dados seguem as regras da árvore. Nada é enviado: a conta é feita no seu navegador.

Missão do cupom
Como o código é calculado

O código depende só do que aparece no cupom: a missão, cada dado, o nº de erros e a data e hora até o minuto. Espaços, setas, colchetes, acentos e maiúsculas não importam (69 → 48 → None e 69->48->none dão o mesmo código). Se um único número for trocado na imagem, o código deixa de bater.

Limite: o simulador roda no navegador e o código-fonte é público, então quem estudasse o programa conseguiria montar um cupom falso com código válido. A página pega imagens editadas e cupons inventados à mão, que são os casos comuns.
