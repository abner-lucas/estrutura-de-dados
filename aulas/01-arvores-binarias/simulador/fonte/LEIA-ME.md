# Simulador de Árvore Binária de Busca · fonte

Código-fonte do simulador publicado em `../index.html`. Requer Node.js: `npm install`, depois `npm run dev` (edição) ou `npm run build` (atualiza `../index.html`).

Identidade visual do portal aplicada com `../../../../ferramentas/aplicar-identidade.cjs`.
Código da aula: `src/code.ts` · Execução passo a passo e perguntas: `src/tracer.ts` · Árvore animada: `src/TreeView.tsx`.
